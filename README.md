# 우리집 재무관리 v1.0 프로토타입

현재 버전은 **서버 연결 전 로컬 프로토타입**입니다.

## 포함 기능
- 월별 수입 / 지출 / 저축·투자 입력
- 공동 / 남편 / 아내 주체 구분
- 월별 대시보드
- 연간 저축·투자 목표
- 카테고리별 월 예산
- 자산 / 부채 / 순자산
- 거래 휴지통 및 복구
- 변경 이력
- JSON 전체 백업 / 복구
- CSV 거래내역 내보내기
- PWA 기본 설정 및 오프라인 캐시

## 중요한 제한
현재 데이터는 **해당 브라우저의 localStorage**에 저장됩니다.
따라서 남편/아내 기기 간 실시간 공동 작업은 아직 지원하지 않습니다.

공동 작업은 다음 단계에서 Supabase를 붙여서:
1. 각자 로그인
2. 하나의 Household 공유
3. 실시간 거래 동기화
4. 서버 백업
5. 사용자별 변경 이력
으로 확장합니다.

## 아이패드에서 테스트하는 가장 쉬운 방법
로컬 파일을 Safari에서 직접 여는 것보다는 GitHub Pages / Vercel 등에 정적 배포하세요.

### GitHub Pages
1. 이 폴더의 파일을 GitHub 저장소에 업로드
2. Settings → Pages
3. Deploy from a branch
4. main / root 선택
5. 생성된 주소를 Safari에서 열기
6. 공유 버튼 → 홈 화면에 추가

## 버전 관리 원칙
- App Version: 1.0.0
- DB Version: 1
- 업데이트 전 JSON 백업
- DB 구조 변경 시 별도 migration 적용
- 코드 롤백과 데이터 롤백을 분리
